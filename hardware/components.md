# Components

Everything below is derived from the firmware. Anything the code does not state is marked **Not specified in the source code**.

| Component | Quantity | Purpose | Connection |
| --------- | -------: | ------- | ---------- |
| ESP32 development board (DevKit / WROOM-style; exact model: **Not specified in the source code**) | 1 | Main controller: runs the Arduino IoT Cloud client, reads switches, drives relays | See [wiring.md](../docs/wiring.md) |
| Relay module, 6 channels, active-LOW inputs (`RELAY_ACTIVE_LOW true`; make/model, coil voltage, optocoupler: **Not specified in the source code**) | 1 | Switches the appliances | IN1–IN6 ← GPIO 23, 22, 21, 19, 18, 5; VCC and GND: see note below |
| Physical wall switch (momentary push-button or maintained toggle; both work with the code) | 6 | Manual / local control, one per relay channel | One terminal → GPIO 32, 33, 25, 26, 27, 14 (switches 1–6); other terminal → GND |
| Wi-Fi status LED (onboard or external: **Not specified in the source code**) | 1 | Blinks when connected to the cloud, solid when not | GPIO 2 (`WIFI_LED`) |
| Appliances / loads (type, voltage, current: **Not specified in the source code**) | up to 6 | Devices being controlled | Via relay contacts (contact terminals used: **Not specified in the source code**) |
| Power supply for ESP32 and relay module (voltage/current: **Not specified in the source code**) | – | Powers the control side | **Not specified in the source code** |

**Note on relay VCC/GND:** the code cannot tell us which supply voltage the relay module uses. Follow your relay module's datasheet. The ESP32 and relay module need a **common GND** for the signal lines to work.

## Electrical safety

If the relays switch AC mains, the load side is hazardous. Ratings of the relay module and loads are not specified here. Check them yourself before connecting anything.
